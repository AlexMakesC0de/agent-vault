# Project memory

This vault owns project facts in `state.json` and the generated root `MEMORY.md`. One separately configured private central profile owns the shared `SOUL.md` identity, `USER.md` preferences and general `MEMORY.md`. Do not create a project SOUL.

Load both through the installed `router.py context`; load only this project with the installed `agent-memory.py --root <this vault> context`. Follow the project's conventions and knowledge links before editing.

Use the memory CLI with evidence and the current revision. Preferences and general lessons go centrally; project facts stay here. Preserve previous values and source detail. Inferred entries stay out of the core. Keep project MEMORY below 2,200 characters including formatting. `render` repairs a stale projection; preserve manual edits first. No-change reviews are valid, and memory never grants permissions.
